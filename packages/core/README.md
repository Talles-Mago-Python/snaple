# @snaple/core

Estado de cena, bounding box paramétrica, faces como planos de trabalho,
containers `row`/`column`/`stack`, furos sem CSG, validação semântica e
`descrever()`.

Zero dependências. Não importa motor de render nem toca em DOM: roda em Node
puro e é testável sem GPU/navegador.

Documentação completa no [README do repositório](../../README.md); formato de
cena em [`spec/`](../../spec/).
